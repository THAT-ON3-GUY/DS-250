Now all the numbers are in a standard format, I’ll try to break them apart into 3 separate pieces: area code, first 3, and last 4

phone_3.with_columns(
    pl.col('ph')
      .str.extract(r"^(\d{3}).*$")     
      .alias('area_code')
    , pl.col('ph')
        .str.extract(r"^\d{3}(\d{3}).*$")
        .alias('next_3')
    , pl.col('ph')
        .str.extract(r"^.*(\d{4})$")
        .alias('last_4')
)
